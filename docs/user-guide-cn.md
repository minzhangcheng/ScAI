# ScAI 用户指南

本指南按照从研究准备到报告审阅的典型分析流程编写，面向希望在保留科学决策控制权的同时使用 ScAI 协同 AI 智能体的生物医学研究者。

## ScAI 的功能

ScAI 是一个通用的多智能体分析平台。它协调各专用智能体检查上传的数据、提出分析计划、执行分析、查阅文献、综合研究发现并生成报告。该工作流以迭代方式运行：智能体会在预设的决策节点展示计划、注释、候选研究方向和轮次总结，您可以在这些节点批准、修订、补充或停止工作。

主工作流需要三个**核心智能体**：

- **PI**：协调研究策略、审阅各智能体的发现并综合结论。
- **Bioinformatics**：在分析工作区中执行计算分析。
- **Literature**：检索并总结相关证据。

其他智能体均为可选。例如，拥有适当图像时可使用 Pathology；Biochemistry 可评估相关测量数据或图像；Painter 可生成图形摘要。它们能否发挥作用取决于您的数据，以及是否已为各智能体配置合适的模型。

ScAI 支持探索性分析和后续分析，但不能替代科学判断。应将其生成的解释、细胞标签、文献总结、因果推断和候选机制视为需要审阅的假设。**AI 解释并非实验验证。**请使用适当的统计方法、来源文献、正交检测和前瞻性实验确认重要结论。

## 开始之前

创建分析前，请准备好科学背景和数据：

1. 写出简明的研究问题，并确定主要的生物学比较。
2. 记录物种、组织或生物系统、检测类型、实验条件、对照、批次和已知协变量。
3. 确定每个实验组和样本分别对应哪些文件。尽可能使用含义明确的文件名。
4. 检查文件是否完整、可读，并已按照所在机构和研究方案的要求完成去标识化处理。
5. 确定预期的阳性和阴性对照、已知标志物模式以及重要的技术局限性。
6. 获取拟使用的模型提供商的 API 凭据。

不要仅仅因为某个质量控制阈值常用于其他研究，就将其作为通用阈值直接套用。合适的过滤条件取决于检测方法、平台、样本质量、实验设计、预期生物学特征和实际观测到的数据分布。应要求 Bioinformatics 智能体展示 QC 分布，并结合您的研究背景说明所提过滤方案的依据。

## 配置 API 访问

开始分析前打开 `API Settings`（API 设置）。仅输入您获授权使用的提供商凭据，然后选择 `Save Config`（保存配置）。可用模型取决于已配置的提供商访问权限。

![模型提供商凭据的 API 密钥设置](images/api-key-settings.png)

按以下说明填写各字段：

- `Default LLM Server`（默认 LLM 服务器）：输入 OpenAI 兼容模型服务的基础 URL，并包含提供商要求的 API 版本路径。请使用所在机构或模型提供商提供的地址。
- `API Key`（API 密钥）：输入默认模型服务的凭据。仅在需要核对内容时使用眼睛图标，并且不要在屏幕截图、报告或共享的屏幕录像中暴露密钥。
- `PubMed Email`（PubMed 邮箱）：输入一个有人维护的联系邮箱，用于 NCBI E-utilities 请求。该字段用于文献检索，而非用户登录。
- `Proxy Server`（代理服务器）：仅当所在机构要求外部 API 请求通过 HTTP/HTTPS 代理时，才填写此可选字段。

保存后：

1. 检查能否为三个核心智能体 PI、Bioinformatics 和 Literature 分别输入模型。模型标识符是由提供商定义的自由文本值；ScAI 不会列出您的账户可用的每个模型。
2. 选择 `Start Analysis`（开始分析）时，ScAI 会验证已配置的服务和凭据。如果验证失败，请使用 `Reconfigure API Key`（重新配置 API 密钥）修正设置。`Ignore Error`（忽略错误）只会绕过预检，之后调用模型时仍可能失败。
3. 如果计划使用可选智能体，也应确认有适合该智能体的模型可用。
4. 选择外部模型提供商时，请遵守所在机构的数据治理规定，尤其是在处理敏感数据或受控数据时。

模型选择为空会禁用相应的可选智能体。核心智能体缺少模型时，工作流的相应部分将无法继续，并可能弹出失败决策对话框。

## 创建分析

在工作区中选择 `New Analysis`（新建分析）以创建研究会话。

![新建分析入口](images/new.png)

提供清晰的标题和研究目标。有效的研究目标应说明：

- 生物系统和物种。
- 待比较的组别或条件。
- 核心问题或终点。
- 重要约束、已知混杂因素或预期输出。

应优先使用聚焦的目标，例如“在考虑供体和批次结构的情况下，描述指定处理组与对照组之间的细胞状态差异”，而不是“分析所有内容”这类宽泛要求。ScAI 可在后续阶段建议其他方向，因此初始目标应明确优先事项，同时避免预先设定答案。

根据您希望监督分析的密切程度设置 `Round Wait Time`（轮次等待时间）：

- `No wait`（不等待）：每轮结束后自动继续，不提供常规反馈时段。
- 正数倒计时：开启有时限的反馈窗口。开始输入内容或添加文件会暂停浏览器中显示的计时器，但不会可靠地延长服务端等待期限。
- 手动等待选项：选择后，工作流会停留在反馈节点，直至您采取操作。

当某项决策必须保持待处理状态直至专家响应时，请使用手动等待选项。`Round Wait Time` 还会影响有时限的计划和反馈对话框，因此对于每个决策节点都需要批准的研究，不要选择 `No wait`。不要将已暂停的浏览器计时器视为不受限制的审阅时间。

## 定义实验组并上传数据

请先定义实验组，再分配文件。组别标签应反映实际研究设计，而不应代表您期望分析得出的结论。

对于每个组：

1. 输入唯一且描述明确的组名。
2. 将样本数设置为上传数据所代表的独立生物学样本数量。
3. 根据需要，为对照、处理、时间点、基因型或其他主要设计因素添加组别。
4. 在元数据或研究描述中保留批次、供体、受试者和配对信息。

随后，在相应的数据区域上传每个文件。对于参与实验比较的文件，请分配正确的 `group`（组别）、`sample`（样本）和 `data type`（数据类型）。仅当相应区分确实不适用或无法恢复时，才使用 `No group distinction`（不区分组别）或 `No sample distinction`（不区分样本）。继续之前务必核对每项分配；样本与组别映射错误可能导致下游比较无效。

![实验组和数据上传控件](images/data-upload.png)

实用上传建议：

- 尽可能上传可直接用于分析的受支持文件，并同时提供解释这些文件所需的元数据。
- 保持生物学重复彼此独立。不要将技术文件标记为独立的生物学重复。
- 对于多模态研究，应明确说明测序、病理、生化和元数据文件之间的对应关系。
- 当预定义选项无法准确描述文件时，请使用自定义数据类型字段。
- 不要仅仅因为某个文件可用就上传它。只应纳入能够在实验设计和数据治理约束下得到合理解释的数据。

每个区域的上传控件各不相同。Pathology 接受界面中列出的常见科研图像格式。测序选项和可接受格式会随所选数据类型而变化；例如，上图所示的单细胞选择器接受可直接分析的 `.h5ad` 或 10x `.h5` 数据。Bulk 矩阵和其他受支持的模态会显示各自的文件选项。生化输入既可作为结构化测量值录入，也可作为表格、电子表格、文本或图像上传。请始终遵循当前所选上传控件显示的格式要求，而不要通过重命名不兼容的文件来尝试上传。

## 配置智能体

创建分析并确定数据类型后，打开 `Agent Settings`（智能体设置）。

![各智能体的模型和行为设置](images/agent-settings.png)

请按以下优先顺序配置智能体：

1. 为 **PI**、**Bioinformatics** 和 **Literature** 三个核心智能体分配模型。
2. 仅当存在相关数据且已配置合适模型时，才启用可选智能体。
3. 仅当研究确实需要有意偏离默认设置时，才调整各智能体的提示词和温度。
4. 仅为需要检查图像且所用模型支持此能力的智能体启用视觉功能。

不同智能体显示的控件有所不同。请检查当前所选智能体显示的控件：

- `Model`（模型）：输入所选提供商开放的准确模型标识符。模型名称因提供商而异。
- `Vision Support`（视觉支持）：仅当显示此开关、所选模型接受图像输入且智能体需要检查图像时才启用。PI 的视觉能力可用于审阅图形。Pathology 需要具备视觉能力的模型来解读切片，但其卡片不使用同样的独立 `Vision Support` 开关。
- `LLM Server / API Key`（LLM 服务器/API 密钥）：保持各智能体的覆盖设置折叠或留空，即可使用默认 API 配置。仅当某个智能体必须使用其他提供商、端点或凭据时才展开设置。
- `Temperature`（温度）：较低值通常有利于生成一致的分析输出；较高值允许更大变化。除非有记录充分的理由，否则请使用默认值。
- `System Prompt`（系统提示词）：用于定义智能体的角色和约束。修改它可能改变科学分析行为，因此应记录并审阅每一项自定义内容。选择 `Reset`（重置）可将所选智能体恢复为默认设置；完成预期修改后选择 `Save`（保存）。

Literature 智能体使用专门的文献与检索设置，而不是其他智能体所显示的全部标准模型控件。请单独检查其 PubMed 和深度研究配置。

当分析工作重视可重复性和精确遵循指令时，请采用保守设置。更高的创造性不会让结果在生物学上更加正确。如果自定义提示词，应保持足够的领域中立性，以便检验不同可能性，而不是强制模型支持偏好的机制或诊断。

开始前，请核对以下最低配置：

| 智能体 | 作用 | 要求 |
| --- | --- | --- |
| PI | 策略、审阅、综合和研究方向决策 | 核心；必须选择模型 |
| Bioinformatics | 计算分析和图形 | 核心；必须选择模型 |
| Literature | 证据检索和背景阐释 | 核心；必须选择模型 |
| Pathology | 基于图像的病理评估 | 可选；仅在有相关图像和适用模型时使用 |
| Biochemistry | 指标和图像解读 | 可选；仅在有相关测量值或图像时使用 |
| Painter | 生成图形摘要 | 可选；需要兼容的图像生成模型 |
| Supervisor | 审阅 Bioinformatics 步骤并参与详细报告生成 | 可选；快速分析模型通常已足够 |
| Technique | 查询已安装软件包的 API 并总结技术错误 | 可选；快速通用模型通常已足够 |

## 启动并监控分析

打开分析视图，检查研究目标、组别、上传文件和智能体配置，然后选择 `Start Analysis`（开始分析）。

![执行前和执行期间的分析工作区](images/analysis.png)

ScAI 会依次推进多个协同阶段。早期探索通常侧重数据检查、QC、聚类和注释；后续轮次会研究选定的方向并整合证据。具体工作取决于可用数据和已批准的计划。

分析运行期间：

- 观察状态和智能体活动，不要想当然地认为耗时较长的步骤已经失败。
- 及时审阅生成的图形和研究发现。
- 及时响应决策对话框，尤其是低置信度结果需要人工审阅时。
- 如果希望跟踪实时进度，请保持分析页面可用；重新连接后应重新加载当前会话状态。

`Pause`（暂停）和 `Stop`（停止）的含义不同：

- `Pause` 会在协作式检查点暂时阻止工作流继续推进。当您需要时间检查问题或调整设置时使用，之后可恢复同一分析。
- `Stop` 会结束当前分析，而不是暂时将其挂起。根据对话框不同，您可能可以立即终止，也可以停止并总结已完成的工作。确认前请仔细阅读提示，因为已停止的工作不能像已暂停的工作一样恢复。

### 响应模型或智能体失败

如果智能体或模型反复失败，根据失败类型，ScAI 可提供 `Retry`（重试）、`Modify Agent Settings`（修改智能体设置）、`Skip`（跳过）和 `Terminate`（终止）：

- `Retry`：重新运行失败的操作。适用于提供商或网络连接的暂时性问题，或已修正相关智能体设置后。
- `Modify Agent Settings`：打开修正模型、端点、凭据或被禁用核心智能体所需的配置。保存修正后，再返回并重试该步骤。
- `Skip`：在缺少该操作结果的情况下继续。仅当缺失内容并非必要时使用，并应记录由此造成的局限性。
- `Terminate`：结束工作流。当继续分析会导致科学上无效、不安全或不必要的成本时使用。

某些失败对话框会在有限计时器到期时自动选择 `Skip`。请及时处理失败；如果跳过核心步骤或科学上必不可少的步骤会使分析无效，请使用手动等待。标志物资源和物种判定对话框可能提供不同操作；请遵循具体对话框，而不要假设所有失败都具有相同选项。

## 人机协同决策

人工审阅是分析的一部分，并非对分析的干扰。在每个决策节点，都应将提案与研究设计、原始证据、对照和领域知识进行比较。

### 审阅分析计划

`Plan Review`（计划审阅）对话框会总结拟议工作流、阶段、轮次、步骤和预计运行时间。

![计划审阅对话框](images/plan.png)

展开各个步骤可检查方法、输入、预期输出、理由、依赖关系和状态。您还可以下载规划对话，以获得更完整的审计记录。

![展开后的计划步骤详情](images/plan-detial.png)

请选择以下三种操作之一：

- `Approve`（批准）：接受显示的计划并继续。
- `Modify`（修改）：打开反馈字段。请准确说明需要修改的内容及原因，例如保留配对变量、比较指定的对比或增加敏感性分析。
- `Skip`（跳过）：无需批准计划即可继续。请谨慎使用；这并不表示计划已经获得科学认可。

![提供反馈以修改分析计划](images/plan-modify.png)

`Plan Review` 包含倒计时。暂停控件会停止浏览器中显示的计时器，但不会可靠地延长服务端等待期限。如果期限到期前未采取操作，ScAI 将执行该对话框的自动跳过行为。当计划包含需要专家审阅的决策时，请使用手动等待，并在期限前响应。

### 确认细胞注释

对于单细胞工作流，ScAI 会在下游使用标签之前暂停于 `Cell Annotation Confirmation`（细胞注释确认）节点。

![细胞注释确认表](images/cell-annot.png)

请审阅每个聚类的建议细胞类型、置信度、组别或样本比例以及关键标志物。展开聚类可检查备选标签及不确定性的原因；如果有相应信息，还应检查验证证据和重新聚类建议。

![注释置信度、证据和备选标签](images/cell-annot-detail.png)

您可以确认单个聚类，也可以编辑其标签，然后确认所有注释。在对话框中，低置信度聚类会禁用 `Confirm All Annotations`（确认所有注释），直至完成审阅。但是，在 `No wait` 模式下，或服务端有限等待期结束后，工作流可能接受 PI 建议的标签并继续，而无需人工确认。如果低置信度标签必须保持阻塞状态以待专家审阅，请选择手动等待。编辑或手动确认任一聚类后，当前审阅中浏览器的自动确认计时器将停止。

![编辑建议的细胞注释](images/cell-annot-modify.png)

证据不足时，请选择 `Request More Analysis`（请求更多分析）。描述一个边界明确的补充任务，例如比较两个合理标签的标志物表达、检查聚类特异性差异表达，或查阅相关文献。确认前应重新评估更新后的证据。注释标签仍属于分析性解释；如果它们支撑核心结论，应进行独立验证。

### 选择研究方向

探索完成后，请审阅生成的方向预览和支持证据。

![候选研究方向预览](images/direction-preview.png)

从生物学相关性、证据强度、可行性、创新性以及与原始目标的契合程度等方面比较各选项。不要仅仅因为某个方向的叙述听起来很有吸引力就选择它。

![研究方向选项](images/direction-option.png)

当建议方向的范围、比较或措辞需要修正时，请为其添加调整说明；如果候选项均不能代表预期问题，请添加自定义研究方向。候选文本不会被直接编辑；相关说明会纳入后续规划。如果现有证据不足，还可以选择 `Request More Analysis`（请求更多分析）。

![修改建议的研究方向](images/direction-modify.png)

后续轮次开始前，选择一个或多个方向并选择 `Start Innovation Analysis`（开始创新分析）。也可以选择 `Let PI Decide`（由 PI 决定）。在 `No wait` 模式下，或有限的方向选择计时器到期时，将采用 PI 决策路径。所选方向集合及相关说明决定分析工作的重点。

![已确认的研究方向选择](images/direction-selected.png)

### 提供轮次反馈

每轮结束时，`Round Feedback`（轮次反馈）对话框会显示 PI 总结、各智能体的关键发现以及补充数据请求。

![轮次总结和反馈控件](images/round-summary.png)

在此节点，您可以：

- 输入下一轮指导意见，包括修正内容、优先事项、其他可能解释或要求进行的敏感性分析。
- 上传补充数据，并将每个文件分配给相关的智能体、组别、样本和数据类型。
- 使用跳过/继续操作，在不提供指导意见的情况下继续。
- 立即停止；如果提供相应选项，也可停止并总结已完成的工作。

开始输入内容或添加文件时，浏览器倒计时会暂停，也可以手动暂停；但这不会可靠地延长服务端期限。`No wait` 会立即继续。使用有限等待时，期限到期并经过短暂的服务端缓冲后，工作流最终会在不提交尚未发送的指导意见或文件的情况下继续。发送补充数据前，请核对样本身份和目标智能体。

### 审阅整合选项

完成一批研究方向后，ScAI 可能会综合跨方向证据，并询问是继续研究整合候选方向，还是完成当前分析。

![跨方向整合审阅](images/integrate.png)

如果有整合报告，请进行审阅。选择一个或多个候选方向并继续、完成当前分析，或让 PI 决定。如果整合倒计时结束，将采用 PI 决策路径。除非数据和外部证据能够证实，否则应将跨方向关联视为假设。

## 审阅结果和报告

打开 `Results`（结果），检查已完成的输出、图形、总结和特定方向的研究发现。

![包含分析输出的结果工作区](images/result.png)

请按照从证据到解释的顺序审阅结果：

1. 确认每项输出使用了哪些样本、组别和对比。
2. 检查 QC 分布、被排除的观测值和警告。
3. 核对图形标签、单位、图例、分母和统计方法。
4. 区分直接观测结果、智能体解释和源自文献的背景信息。
5. 比较不同智能体的结论，并记录分歧或缺失的证据。
6. 解释为何执行某项分析时，应回顾已批准的计划和人工决策。

简要总结对研究问题、方法和主要发现进行了精炼综合。可先用它了解整体情况，再将重要表述追溯到详细结果和图形。

![简要结果总结](images/result-brief-summary.png)

如果已配置，图形摘要会提供可视化概述。请核对每个标签和所呈现的关系；生成的插图可能会简化、夸大或错误表达证据。

![生成的图形摘要](images/result-graphic-abstract.png)

打开 `Report`（报告），查看可用的报告版本和可下载输出。

![报告面板](images/report.png)

分享或引用报告前：

- 核实所述方法与实际分析及已批准的修改相符。
- 对照原始出版物核查参考文献。
- 直接根据表格、图形或可重复输出确认数值结论。
- 说明跳过智能体、步骤失败、模态缺失、注释不确定或元数据不完整所造成的局限性。
- 区分探索性关联与已验证的机制及因果结论。
- 请具备相应资质的研究人员审阅最终科学解释。

## 实用核对清单与故障排除

### 分析前核对清单

- [ ] 研究目标和主要比较均已明确。
- [ ] 组别、样本、重复、配对、批次和协变量均已正确表示。
- [ ] 上传文件可读，已按要求去标识化，并已分配至正确的组别、样本和数据类型。
- [ ] PI、Bioinformatics 和 Literature 均已配置模型。
- [ ] 仅当有相关数据和适合的模型支持时，才启用可选智能体。
- [ ] QC 决策将依据研究背景和实际观测分布，而不是通用阈值。

### 决策节点核对清单

- [ ] 计划中的方法和对比符合研究设计。
- [ ] 当低置信度注释必须保持阻塞状态以待专家审阅时，已启用手动等待。
- [ ] 已根据标志物、证据和备选标签审阅低置信度注释。
- [ ] 补充请求具体且可回答。
- [ ] 所选研究方向有证据支持且切实可行。
- [ ] 轮次反馈记录了修正内容、局限性和下一步优先事项。
- [ ] 计时器不会在无人操作时替代需要专家审阅的决策。

### 最终审阅核对清单

- [ ] 已对照底层输出检查图形和统计结果。
- [ ] 已从来源文献核实文献引用和总结。
- [ ] 已将跳过或失败的步骤披露为局限性。
- [ ] 已清楚区分观测结果、解释、假设和因果结论。
- [ ] 已为核心结论制定适当的独立验证计划。

### 故障排除

| 问题 | 检查内容 | 建议操作 |
| --- | --- | --- |
| 核心智能体无法启动 | PI、Bioinformatics 或 Literature 没有可用的模型或凭据 | 使用 `Modify Agent Settings`，或返回 `API Settings` 和 `Agent Settings`，保存修正后重试 |
| 可选智能体未出现 | 其模型为空、不受支持，或与上传的数据无关 | 仅当需要相应数据和分析时才配置合适的模型 |
| 计划在科学上不完整 | 缺少对比、协变量、对照、方法或预期输出 | 选择 `Modify` 并提供具体、可检验的反馈 |
| 注释置信度较低 | 标志物支持、备选标签、不确定性原因、比例、验证证据和等待模式 | 使用手动等待；确认或编辑每个低置信度聚类；如果证据仍然不足，请求补充分析 |
| 结果似乎由 QC 选择所驱动 | 过滤条件可能不适合该检测方法或样本分布 | 检查 QC 图，要求说明依据并进行敏感性分析，避免套用无关研究的阈值 |
| 某轮次需要更多背景信息 | 缺少元数据或相关模态 | 在 `Round Feedback` 中添加聚焦的指导意见，或上传已正确分配的补充数据 |
| 操作反复失败 | 提供商可用性、模型访问权限或智能体配置 | 修正暂时性问题或配置问题后选择 `Retry`；选择 `Skip` 时记录局限性；如果继续操作无效，则选择 `Terminate` |
| 需要时间审阅 | 工作流仍处于活动状态，但并不打算终止 | 使用 `Pause`，检查问题后再恢复 |
| 应当结束分析 | 继续分析不再有用或不再符合科学要求 | 使用 `Stop`；根据提供的选项选择立即终止或生成总结 |
| 报告中的结论似乎过强 | 该结论可能混合了分析结果、文献背景和 AI 推断 | 将其追溯至主要输出和来源，修订措辞，并要求进行独立实验验证 |

如有疑问，请保留审计记录：记录您修改了什么、为何修改、哪些证据支持该决策，以及仍存在哪些不确定性。
